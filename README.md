# Central DP ILED

Portal único do Departamento Pessoal da ILED Produções: Painel DP, Lançamentos, Notas Fiscais, Caderno, Cadastro geral e Calendário de pagamentos.

- `index.html` — a Central inteira (um arquivo só)
- `_headers` e `robots.txt` — impedem que o site apareça no Google

Os dados ficam no Supabase (projeto **DP ILED PRODUCOES**), protegidos por login.
Este repositório deve ser **privado**.
